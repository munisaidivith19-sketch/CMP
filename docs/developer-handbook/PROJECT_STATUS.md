4. Kotlin release builds are signed with the debug key.
5. `/api/health` does not check MongoDB; no error-monitoring service; no automated backups.
6. Clubs and discussions have no API tests; no browser E2E tests.

8. Server suite: 2 deterministic failures in `gate-exit-campus-day.test.js` (mixed `clock.now` / `new Date()`), 1 intermittent file failure (`announcement-tampering.test.js`). CI on GitHub will also fail on the gate-exit tests until this is resolved.
